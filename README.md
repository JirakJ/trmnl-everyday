## Original combined source

This repository retains the original combined implementation and Git history for
provenance. Its v0.1.0 release is the legacy combined release; it is superseded by
the separate repositories above. No existing release artifacts have been removed.

The [historical installation guide](docs/LEGACY_INSTALL.md) documents that older
layout. New installations should follow the README in their selected plugin repository.

All seven plugins use the MIT license. Physical TRMNL display operation and private
account integrations have not been verified; consult each plugin's documented scope.
